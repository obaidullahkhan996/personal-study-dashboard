# Personal Study Dashboard 📚

A simple study dashboard built with Python and Streamlit. I created this project to practice Python and build a tool that helps me organize my daily study tasks.

## Features

- Add new study tasks
- View daily study tasks
- Mark tasks as completed
- Track progress with a progress bar
- Choose a subject to study

## Technologies Used

- Python
- Streamlit

## How to Run

1. Clone this repository.
2. Install Streamlit:

   ```bash
   pip install streamlit
   ```

3. Run the application:

   ```bash
   python -m streamlit run app.py
   ```

4. Open the local URL displayed in your terminal.

## What I Learned

While building this project, I practiced Python lists, loops, conditional statements, functions provided by Streamlit, and session state.
